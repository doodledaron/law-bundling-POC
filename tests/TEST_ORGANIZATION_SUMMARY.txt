NAMING CONVENTION:
================================================================================

Format: NN_feature_name_description_test.py

NN: Sequential number (01, 02, 03, 04, ...)
feature_name: Main feature being tested (summarization, relevance, etc.)
description: Brief description of test focus
_test.py: Standard test file suffix

Examples:
- 01_summarization_container_warmup_test.py
- 04_relevance_extraction_test.py

AUTH MECHANISM (ALL FILES):
================================================================================

Environment Variables (.env file):

REQUIRED:
  GEMINI_API_KEY=your_api_key_here
  API_KEYS=test-key-1,test-key-2,test-key-3

OPTIONAL:
  API_BASE_URL=http://localhost:8000
  REDIS_URL=redis://localhost:6379/0

Loading method:
  - Tests use load_env_file() to read .env
  - First API key from API_KEYS comma-separated list is used
  - Authentication header: X-API-Key
